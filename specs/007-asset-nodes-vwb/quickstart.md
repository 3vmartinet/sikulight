# Quickstart: Asset Workflow Nodes

## Goal
Automate visual interactions by dragging and dropping assets from the registry onto the VWB canvas.

## Workflow
1. **Open** the Visual Workflow Builder.
2. **Expand** the Asset Registry panel.
3. **Drag** an image asset onto the canvas.
4. **Configure** the node using the Right Pane (select action, set Ignore Error).
5. **Connect** the Success/Failure ports to subsequent nodes.
6. **Execute** the workflow.
