# Implementation Plan: Embedded Workflow Assets

## Summary

The feature introduces the `.macaque` file format (ZIP-based) as the standard storage and transport format for all workflows. Each `.macaque` file bundles the workflow JSON and its referenced image assets, ensuring portability by default. On load, assets are extracted to an isolated, temporary folder which is displayed in the **Workflow Assets** tab within the Asset Manager. These temporary assets are automatically cleaned up upon tab closure or selectively at application startup if orphaned.

## Technical Context

**Language/Version**: Flutter (Dart) ^3.11.5, Python 3.10+ (FastAPI)  
**Primary Dependencies**: `archive` (for ZIP/macaque), `path_provider` (for temp storage)  
**Storage**: ZIP-based primary format (`.macaque`), local temporary filesystem for active sessions  
**Testing**: Flutter widget tests, Dart unit tests, pytest (for any engine changes)  
**Target Platform**: Desktop (macOS, Windows, Linux)
**Project Type**: Desktop application (Flutter) + Local engine (Python)  
**Performance Goals**: Load/Save < 2s for 10 assets  
**Constraints**: Selective startup cleanup of `sikulite_imports`, no hard size limits on bundled assets  
**Scale/Scope**: Unified format for all workflows
